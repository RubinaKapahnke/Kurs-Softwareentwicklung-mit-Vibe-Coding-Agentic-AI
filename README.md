# 🚀 Vibe Coding Kurs: Von der Idee zum Projekt

Willkommen zum **Vibe Coding Kurs**! Dieses Repository ist unser Workspace, um die Grundlagen der modernen Softwareentwicklung im "Vibe Coding"-Stil zu erlernen. 

Beim Vibe Coding nutzen wir die natürliche Sprache und KI-Unterstützung, um schnell Prototypen zu bauen, ohne dabei die Struktur und Qualität aus den Augen zu verlieren.

---

## 🎯 Ziel des Kurses
Das Ziel ist es, den gesamten Entwicklungszyklus von A bis Z in einem **engen Setup** zu durchlaufen. Wir begrenzen die Vielfalt der Werkzeuge bewusst, um uns auf die Erfolgsfaktoren zu konzentrieren: Zusammenarbeit, Prompting und saubere Integration.

### Was wir bereits gelernt haben:
- [x] Was eine `.md` Datei ist und wie man sie formatiert.
- [x] Grundlegende Nutzung von **VS Code**.
- [x] Installation von Erweiterungen in VS Code.
- [x] Nutzung von **GitHub Copilot** in VS Code.
- [x] Einem Repository beitreten, Branches erstellen, Commits pushen und Merge-Konflikte lösen.

---

## 🛠 Das Setup
Um den Fokus zu behalten, arbeiten wir ausschließlich mit diesem Stack:
* **Editor:** VS Code
* **KI-Assistent:** GitHub Copilot
* **Framework:** Angular (mit TypeScript)
* **UI-Library:** Angular Material
* **Datenformat:** JSON

---
