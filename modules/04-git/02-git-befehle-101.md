# Git 101: Einstieg und Grundlagen

## Was ist Git?
Git ist ein verteiltes Versionskontrollsystem, das von Linus Torvalds entwickelt wurde. Es hilft Entwickler:innen, Änderungen am Code nachzuvollziehen, parallel zu arbeiten und verschiedene Versionen eines Projekts zu verwalten.

## Wofür wird Git genutzt?
- **Versionsverwaltung:** Jede Änderung am Code wird gespeichert und kann zurückverfolgt werden.
- **Zusammenarbeit:** Mehrere Personen können gleichzeitig am gleichen Projekt arbeiten, ohne sich gegenseitig zu stören.
- **Experimentieren:** Neue Features oder Bugfixes können in eigenen Branches ausprobiert werden.

## Die wichtigsten Grundbefehle
- `git init` – Erstellt ein neues Git-Repository
- `git clone <URL>` – Klont ein bestehendes Repository
- `git status` – Zeigt den aktuellen Stand der Arbeitskopie
- `git add <Datei>` – Merkt Änderungen für den nächsten Commit vor
- `git commit -m "Nachricht"` – Speichert die Änderungen dauerhaft
- `git push` – Überträgt Änderungen ins entfernte Repository (z. B. GitHub)
- `git pull` – Holt Änderungen vom entfernten Repository

## Warum ist Git ideal für Vibe Coding?
- **Flexibilität:** Schnelles Wechseln zwischen Versionen und Ideen
- **Sicherheit:** Änderungen gehen nicht verloren, alles ist nachvollziehbar
- **Kollaboration:** Perfekte Grundlage für gemeinsames Arbeiten und KI-gestützte Entwicklung

---

**Tipp:**
Mit `git log` kannst du die Historie aller Commits einsehen und nachvollziehen, wie sich das Projekt entwickelt hat.
