# GitHub im Kurskontext

Diese Datei beschreibt, wie GitHub in diesem Kurs eingesetzt wird.

## Rolle von GitHub im Kurs

GitHub ist in diesem Kurs die gemeinsame Plattform fuer:

- Zusammenarbeit an Dateien
- Nachvollziehbare Aenderungen (Commits, Pull Requests)
- Austausch ueber Aufgaben und Feedback

## GitHub und Git: kurz unterschieden

- Git ist das lokale Versionskontrollsystem.
- GitHub ist die Online-Plattform fuer Repositories und Teamarbeit.

## So nutzen wir GitHub im Kurs

1. Das Kurs-Repository enthaelt zentrale Materialien und Uebungen.
2. Teilnehmende arbeiten zusaetzlich im eigenen Uebungs-Repository.
3. Dozentinnen und Dozenten geben Feedback ueber GitHub.

## Relevante GitHub-Features im Kurs

- Repositories: Projektinhalt und Historie
- Branches: parallele Arbeitsstaende
- Pull Requests: Aenderungen vorschlagen und reviewen
- Issues: Aufgaben, Fragen und Hinweise sammeln
