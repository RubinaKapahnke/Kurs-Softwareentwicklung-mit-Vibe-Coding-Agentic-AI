# GitHub-Features im Kurs und eigenes Repository

Diese Datei ist kursspezifisch und beschreibt die praktische Anwendung im Kurs.

## Repositories im Kurs

- Kurs-Repository: zentrale Materialien, Module und Uebungen
- Eigenes Uebungs-Repository: persoenliche Loesungen

## Ein neues Uebungs-Repository im Browser erstellen

1. GitHub oeffnen und einloggen.
2. "New repository" waehlen.
3. Namen vergeben, z. B. `vibe-coding-uebungen`.
4. Sichtbarkeit auf "Private" setzen.
5. "Initialize with README" aktivieren.
6. Repository erstellen.

## README fuer das eigene Repo

Nutze diese Vorlage:

- [README-template-tn-repo.md](./README-template-tn-repo.md)

Du kannst die README entweder direkt im Browser bearbeiten oder den Text aus der Vorlage hineinkopieren.
