# Lektion 05: Trainerin einladen

## Ziel

Du gibst der Trainerin Zugriff auf dein Repository.

## Schritt-für-Schritt

1. Repository öffnen.
2. Settings auswählen.
3. Links unter Access auf Collaborators gehen.
4. Add people klicken.
5. RubinaKapahnke eingeben und auswählen.
6. Add collaborator bestätigen.

## Fallback

- Collaborators nicht sichtbar: Prüfe, ob du im eigenen Repository bist.
- Profil erscheint nicht: Benutzernamen vollständig eingeben.

## Hinweis

Pending invite ist normal, bis die Einladung angenommen wurde.

## Erfolgskriterium

Die Einladung wurde gesendet.
