1. Das Chaos verstehen
  a. Markdown file anlegen: `Was-ist-git_v1_0_0.md` Der Datei eine grundlegende Struktur geben (Überschriften?)
  b. Ein Teilnehmer befüllt das erste Kapitel und versioniert die Datei im Dateinamen
  c. Andere Teilnehmer befüllen zeitglich die anderen Kapitel und versionieren die Datei im Dateinamen. Hierbei dürfen auch Korrekturen am bestehenden Text aus b. vorgenommen werden
  d. Diskutiert die Problematik: Versionsvergabe? Welche Korrekturen müssen in die aktuellste Version von wem eingepflegt werden? Wer kombiniert alle Änderungen? Wer hat die finale Version? Was tun, wenn es sich um mehr als eine Datei handelt?
