# Lektion 06: Erste Übungen im eigenen Repository

## Ziel

Du machst deine ersten GitHub-Aktionen direkt im Browser.

## Übung 1: Neue Datei anlegen

1. Add file -> Create new file
2. Dateiname: uebung-01.md
3. Inhalt eintragen
4. Commit changes mit passender Nachricht

## Übung 2: README bearbeiten

1. README.md öffnen
2. Stift-Icon klicken
3. Eine Zeile ergänzen
4. Commit changes ausführen

## Fallback

- Add file nicht sichtbar: In den Code-Tab wechseln.
- Commit-Button ausgegraut: Erst Inhalt einfügen.

## Erfolgskriterium

Mindestens 2 Commits sind im Repository sichtbar.
