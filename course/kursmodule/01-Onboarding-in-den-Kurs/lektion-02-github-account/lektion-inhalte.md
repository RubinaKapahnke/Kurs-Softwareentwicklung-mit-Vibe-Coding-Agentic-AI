# Lektion 02: GitHub-Account anlegen

## Ziel

Du hast einen GitHub-Account erstellt, deine E-Mail bestätigt und kannst den Account im Kurs nutzen.

## Vor dem Start

- [ ] Du hast Zugriff auf dein E-Mail-Postfach.
- [ ] Du nutzt einen aktuellen Browser (z. B. Edge, Chrome oder Firefox).
- [ ] Du hast den Kurschat griffbereit, falls etwas nicht funktioniert.

## Kapitel 1: Was ist GitHub?

GitHub ist eine Plattform im Web, auf der du Code speichern, versionieren und teilen kannst.

### Warum brauchen wir GitHub im Kurs?

1. Dein eigenes Übungs-Repository liegt auf GitHub.
2. Das gemeinsame Kurs-Repository liegt ebenfalls auf GitHub.
3. Dozent*innen können deine Commits sehen und dir Feedback geben.

GitHub ist kostenlos nutzbar. Du brauchst nur einen Account.

## Kapitel 2: Account erstellen

1. Öffne https://github.com.
2. Klicke auf Sign up.
3. Falls Sign up nicht sichtbar ist: Öffne direkt https://github.com/join.
4. Gib E-Mail, Passwort und Benutzernamen ein.
5. Schließe die angezeigten Verifizierungs-Schritte ab.
6. Öffne dein E-Mail-Postfach und bestätige deine E-Mail-Adresse.
7. Falls keine E-Mail ankommt: Prüfe den Spam-Ordner und fordere die E-Mail erneut an.
8. Nach der Bestätigung ist dein Account einsatzbereit.

### Hinweise

- Der GitHub-Benutzername ist sichtbar.
- Nutze möglichst eine E-Mail-Adresse, die dauerhaft in deinem Besitz bleibt.
- Wähle einen Benutzernamen, den du auch später im Kurskontext verwenden möchtest.
- Nutze einen Passwortmanager im Browser oder auf deinem Gerät, damit du dein Passwort sicher speichern kannst.

## Quiz: Kurze Verständnisfrage

Frage: Wozu dient GitHub im Kurs hauptsächlich?

- [ ] Als E-Mail-Dienst für Nachrichten an Dozent*innen.
- [x] Als Plattform zum Speichern und Teilen von Code mit Versionsverlauf.
- [ ] Als Video-Lernplattform für Kursinhalte.
- [ ] Als lokales Programm auf deinem Rechner, das nur offline funktioniert.

Erfolg: Richtig! GitHub ist deine Plattform für Code und Zusammenarbeit im Kurs.
Fehler: Nicht ganz. Merke: GitHub ist die Plattform im Web, Git ist das Werkzeug für Versionskontrolle.
