# Lektion 03: GitHub-Repositories und Git verstehen

## Ziel

Du verstehst, wie wir GitHub im Kurs nutzen, was Repositories sind und warum Git die Basis für Versionskontrolle ist.

## GitHub im Kurskontext

GitHub ist in diesem Kurs die gemeinsame Plattform fuer Zusammenarbeit an Dateien, nachvollziehbare Aenderungen und den Austausch ueber Aufgaben und Feedback.

### GitHub und Git: kurz unterschieden

- Git ist das lokale Versionskontrollsystem.
- GitHub ist die Online-Plattform fuer Repositories und Teamarbeit.

### So nutzen wir GitHub im Kurs

1. Das Kurs-Repository enthaelt zentrale Materialien und Uebungen.
2. Teilnehmende arbeiten zusaetzlich im eigenen Uebungs-Repository.
3. Dozentinnen und Dozenten geben Feedback ueber GitHub.

## Repositories verstehen

Ein Repository ist der gemeinsame Ort fuer Dateien und die komplette Versionsgeschichte. Im Kurs arbeiten wir sowohl mit dem Kurs-Repository als auch mit deinem eigenen Uebungs-Repository.

### Repositories im Kurs

- Kurs-Repository: zentrale Materialien, Module und Uebungen
- Eigenes Uebungs-Repository: persoenliche Loesungen

## Was wir im Modul 01 konkret brauchen

Im ersten Kursmodul ist Version Control kein Nebenthema, sondern Sicherheitsnetz fuer deinen Lernfortschritt.

Du nutzt Git/GitHub hier vor allem fuer:

- nachvollziehbare Lernschritte (kleine Commits statt grosser Spruenge)
- sichere Zusammenarbeit ueber Branches und Pull Requests
- klare Dokumentation, die andere Menschen und KI lesen koennen

## Praktische Leitplanken fuer Einsteiger:innen

1. Arbeite in kleinen, klar benannten Schritten.
2. Pruefe vor jedem Push kurz mit `git status`.
3. Nutze Commit-Nachrichten, die den Zweck beschreiben.
4. Halte `main` stabil und arbeite fuer Aufgaben in einem Branch.

## Was von GitOps hier schon mitgedacht wird

GitOps selbst ist in Modul 01 noch nicht das Umsetzungsziel. Trotzdem lernst du bereits Grundprinzipien, die spaeter wichtig werden:

- Git als verbindliche Quelle fuer den gewuenschten Stand
- Aenderungen ueber Review-Prozess statt Direkt-Eingriffe
- reproduzierbare Aenderungen durch klare Historie
