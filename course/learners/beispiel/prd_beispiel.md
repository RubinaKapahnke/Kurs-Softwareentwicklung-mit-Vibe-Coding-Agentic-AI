# PRD: Beispielprojekt

Dies ist eine neutrale Beispieldatei für eine Produktbeschreibung. Sie enthält keine echten Teilnehmendendaten.

## 1. Vision & Zielsetzung

Das Beispielprojekt soll zeigen, wie eine einfache Produktidee so beschrieben wird, dass Menschen und KI damit arbeiten koennen.

## 2. Zielgruppe und Problem

- Zielgruppe: Lernende im Kurs
- Problem: Der Einstieg in ein eigenes Projekt braucht eine klare, kleine Struktur.

## 3. Kernfunktionen

- Eine kurze Projektbeschreibung anzeigen
- Nächste Schritte dokumentieren
- Offene Fragen sichtbar machen

## 4. Technische Leitplanken

- Dokumentation in Markdown
- Umsetzung im eigenen Repository
- Kleine, prüfbare Änderungen

## 5. Definition of Done

- [ ] Die Idee ist in 3 bis 5 Saetzen verstaendlich.
- [ ] Mindestens ein nächster Schritt ist konkret.
- [ ] Offene Fragen sind sichtbar.
