## Wissensziele

Nutze die Wissensziele von oben nach unten: erst den Überblick, dann die Grundlagen, dann die Vertiefung.

### Überblick

- [ ] Ich weiß, was VS Code ist und warum es als zentrale Arbeitsumgebung genutzt wird.
- [ ] Ich kann mich im Editor orientieren: Explorer, Editor-Bereich, Terminal.
- [ ] Ich kann die Befehlspalette öffnen und nutzen (Ctrl+Shift+P / Cmd+Shift+P).
- [ ] Ich kann Dateien öffnen, bearbeiten und speichern.

### Grundlagen

- [ ] Ich verstehe, wie VS Code Git, Terminal und Erweiterungen verbindet.
- [ ] Ich kann wiederkehrende Aktionen über Shortcuts oder die Befehlspalette schneller ausführen.
- [ ] Ich erkenne, wie VS Code Dokumentation, Code und KI-Assistenz zusammenbringt.
- [ ] Ich kann Tabs und mehrere Dateien gleichzeitig öffnen.
- [ ] Ich kann Copilot Chat öffnen und eine Frage stellen.
- [ ] Ich kann mit `#` eine Datei als Kontext zu einem Prompt hinzufügen.
- [ ] Ich kann mit `/` Prompt-Dateien aufrufen.
- [ ] Ich weiß, wie ich bei der Meldung "content of the file is newer" mit Compare/Overwrite sicher entscheide.

### Vertiefung

- [ ] Ich passe den Editor so an, dass er besser zu meinem Workflow passt (Theme, Einstellungen).
- [ ] Ich kenne sinnvolle Erweiterungen oder Ansichten für die Arbeit im Repo.
- [ ] Ich nutze VS Code für verschiedene Aufgaben neben Code-Bearbeitung (Markdown, Git, Terminal).
- [ ] Ich nutze Debugging- oder Preview-Features je nach Kontext.
