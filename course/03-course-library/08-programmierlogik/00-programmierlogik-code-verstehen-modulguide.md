# Artikel: Programmierlogik

Dieser Artikel hilft dir, KI-generierten Code besser zu verstehen und in kleinen Lektionen sicher zu verbessern.

## Inhaltsverzeichnis

1. [01-programmierlogik-grundlagen.md](./01-programmierlogik-grundlagen.md)
2. [02-programmierlogik-code-lesen.md](./02-programmierlogik-code-lesen.md)

## Wissensziele

Nutze die Wissensziele von oben nach unten: erst den Überblick, dann die Grundlagen, dann die Vertiefung.

### Überblick

- [ ] Ich kann Variablen, Funktionen und Rückgabewerte in einfachem Code erkennen.
- [ ] Ich kann erklären, was bei einer Bedingung (`if`) passiert.
- [ ] Ich kann in eigenen Worten beschreiben, wie Daten von A nach B fließen.
- [ ] Ich kann KI-generierten Code in kleinen Abschnitten lesen, statt alles auf einmal zu bewerten.

### Grundlagen

- [ ] Ich kann einfache Logikfehler benennen (z. B. falsche Bedingung, leerer Wert, falscher Datentyp).
- [ ] Ich kann einer KI gezielte Rückfragen zum Code stellen, statt nur "funktioniert nicht" zu schreiben.
- [ ] Ich kann eine kleine Funktion Lektionweise vereinfachen oder umbenennen, ohne das Verhalten zu ändern.

### Vertiefung

- [ ] Ich kann begründen, warum eine kleine Strukturverbesserung die Wartbarkeit erhöht.
- [ ] Ich kann einen kurzen "Code-Versteh-Prompt" für wiederkehrende Aufgaben wiederverwenden.
