# Bedienungshilfen

Diese Datei sammelt wiederverwendbare Hinweise zur Bedienung von Kurs-Tool, Editor und Repo-Struktur. Sie ist freiwillig und nicht Teil des Pflichtflusses einzelner Lektionen.

## Kurs-Tool lesen und bedienen

- Oben im Kurs-Tool siehst du deinen Fortschritt über alle Lektionen.
- Innerhalb eines Lektions kannst du Teilaufgaben einzeln abhaken.
- Wenn alle Teilaufgaben erledigt sind, markierst du den Lektion als abgeschlossen.
- Die schmale App-Breite ist Absicht: So kannst du Browser, Editor und Notizen leichter nebeneinander nutzen.

## In VS Code schnell zu Dateien springen

Wenn du eine Datei schnell öffnen willst:

1. Drücke `Strg+P` unter Windows oder `Cmd+P` auf dem Mac.
2. Tippe den Dateinamen ein.
3. Öffne die gewünschte Datei direkt aus der Trefferliste.

Das ist besonders nützlich bei versteckten Ordnern wie `.github/`.

## Wann nutze ich welches Repository?

- Dein eigenes Übungs-Repository ist dein Arbeitsbereich für Übungen, Notizen und Lösungen.
- Das Kurs-Repository enthält Materialien, Aufgaben, zentrale Regeln und Updates.

## Bilder, Links und Materialien im Onboarding

- Onboarding-Lektionen dürfen Bilder gezielt einsetzen, wenn sie Orientierung schaffen oder einen Arbeitsschritt sichtbar machen.
- Links sollen bevorzugt direkt zur passenden Quelle führen.
- Allgemeine Hilfe gehört in zentrale Hilfedateien wie diese, nicht in jede Lektion.

## Wenn du zwischen mehreren Fenstern arbeitest

Ein bewährtes Setup ist:

- links das Kurs-Tool,
- rechts Browser, VS Code oder dein Repository,
- daneben optional Notizen.

So bleibt sichtbar, was du gerade tun sollst, während du es direkt umsetzt.
