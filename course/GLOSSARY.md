# Glossar

Diese Datei sammelt zentrale Fachbegriffe des Kurses in knapper Form. Begriffe sollen in Lektionen weiterhin direkt am Einsatzpunkt erklärt werden. Das Glossar ist die zentrale Referenz für späteres Nachschlagen.

## Git

Git ist das Werkzeug für Versionskontrolle. Es speichert nachvollziehbar, wie sich Dateien im Laufe der Arbeit verändern.

## GitHub

GitHub ist die Plattform im Web, auf der Git-Repositories liegen, geteilt und gemeinsam bearbeitet werden können.

## Repository

Ein Repository ist ein Projektbereich mit Dateien und Änderungsverlauf. Im Kurs gibt es dein eigenes Übungs-Repository und das gemeinsame Kurs-Repository.

## Commit

Ein Commit ist ein gespeicherter Zwischenstand mit einer kurzen Beschreibung der Änderung.

## README

Eine README ist die Startseite eines Repositorys. Sie erklärt knapp, worum es in einem Projekt oder Arbeitsbereich geht.

## Branch

Ein Branch ist ein eigener Entwicklungszweig. Er erlaubt es, Änderungen getrennt vom Hauptstand vorzubereiten.

## Pull Request

Ein Pull Request ist die Bitte, Änderungen aus einem Branch zu prüfen und in einen anderen Branch zu übernehmen.

## VS Code

VS Code ist der Editor, mit dem im Kurs lokal gearbeitet wird.

## GitHub Copilot

GitHub Copilot ist ein KI-Assistenzwerkzeug von GitHub, das direkt in VS Code genutzt werden kann.

## Prompt

Ein Prompt ist eine Eingabe an ein KI-System. Gute Prompts enthalten Ziel, Kontext und klare Erwartungen.

## Kontext

Kontext sind die Informationen, die ein Mensch oder ein KI-System braucht, um eine Aufgabe sinnvoll lösen zu können.
