Dieses Modul erklaert die Grundlagen von Markdown und zeigt dir, wie du Inhalte sauber strukturierst und formatierst.

## Inhalt

1. [Markdown: Grundlagen und Einsatz](./01-markdown-grundlagen.md)

## Selbstcheck

Nutze die Checklisten als Selbstcheck fuer das Markdown-Modul.

### Must have

- [ ] Ich weiss, was Markdown ist und wofuer es im Projekt genutzt wird.
- [ ] Ich kann Ueberschriften (#, ##, ###) schreiben.
- [ ] Ich kann Listen (Aufzaehlung, nummeriert) erstellen.
- [ ] Ich kann Links schreiben: `[Text](URL)`
- [ ] Ich kann Text-Hervorhebung nutzen: `**fett**`, `*kursiv*`, `` `Code` ``
- [ ] Ich kann bestehende Markdown-Dateien lesen und erweitern.

### Should have

- [ ] Ich strukturiere Inhalte so, dass sie fuer Menschen und KI lesbar sind.
- [ ] Ich setze Formatierung bewusst ein, statt Text nur hintereinanderzureihen.
- [ ] Ich erkenne typische Markdown-Muster in README-, Modul- und Uebungsdateien.
- [ ] Ich kann Tabellen erstellen.
- [ ] Ich kann Code-Bloecke mit Sprach-Angabe formatieren (```python, ```json etc).

### Nice to have

- [ ] Ich nutze Markdown als Arbeitsgrundlage fuer Anforderungen und Notizen.
- [ ] Ich entwickle ein Gefuehl dafuer, wann eine Datei erklaerend und wann nachschlagbar sein sollte.
- [ ] Ich kann erweiterte Markdown-Features wie Fussnoten oder HTML-Kommentare nutzen.
- [ ] Ich schreibe Markdown, das sowohl in GitHub als auch in anderen Tools gut aussieht.
