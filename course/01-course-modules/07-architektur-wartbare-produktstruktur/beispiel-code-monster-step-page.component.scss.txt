# Beispiel-Datei: Code-Monster in einer Step-Page-SCSS

ACHTUNG: Diese Datei ist reines Kursmaterial.
Sie ist keine produktive SCSS-Datei und wird von keiner App importiert.
Die Endung `.scss.txt` ist absichtlich gewählt, damit sie nicht versehentlich in Angular eingebunden wird.

## Kontext

Diese Beispiel-Datei zeigt einen verkuerzten Ausschnitt aus einer echten Step-Page-SCSS-Datei der Onboarding-App.

Die echte Datei war zeitweise über 1100 Zeilen lang, weil viele verschiedene Onboarding-Zustaende in einer einzigen Step-Komponente gestaltet wurden.

Das Ziel dieser Datei ist nicht, perfekten Code zu zeigen. Sie zeigt ein Lernmuster:

- viele fachliche Zustaende in einer Datei
- viele schrittspezifische Klassen
- alte Styles, die später nicht mehr gebraucht wurden
- Designentscheidungen direkt in Komponenten statt in Tokens
- wachsender Aufwand beim Suchen, Prüfen und Ändern

## Warum dieser Ausschnitt problematisch ist

Der Code ist nicht deshalb problematisch, weil einzelne Regeln falsch sind. Viele Regeln sind für sich genommen nachvollziehbar.

Problematisch ist die Mischung:

- Header-Design
- Voucher-Design
- Account-Auswahl
- Warnhinweise
- Installations-Tabs
- Aufgabenlisten
- Clone-Hinweise
- Typografie-Regeln
- Layout-Regeln
- Farbentscheidungen

Alles lebt in einer Datei. Dadurch wird jede neue Änderung schwerer:

- Man muss laenger suchen.
- Man erkennt schwerer, welche Klasse zu welchem Schritt gehoert.
- Alte Styles bleiben leichter liegen.
- Neue Änderungen landen wieder in derselben grossen Datei.

## Was man daraus lernen soll

Eine bessere Struktur waere zum Beispiel:

```text
step-page/
├── step-page.component.html
├── step-page.component.scss              # nur Rahmen und gemeinsame Step-Regeln
├── voucher-gate/
├── account-choice/
├── install-instructions/
├── task-list/
└── clone-instructions/
```

Oder zumindest:

```text
styles/
├── _tokens.scss                          # Farben, Typografie, Abstände
├── _step-layout.scss                      # gemeinsame Step-Struktur
└── _forms-and-hints.scss                  # wiederverwendbare Hinweise/Formulare
```

## Merksatz

Wenn eine Datei viele verschiedene Geschichten gleichzeitig erzaehlt, ist sie kein guter Ort mehr für neue Details.
