# Ein GitHub-Repository erstellen

Diese Anleitung zeigt dir Schritt für Schritt, wie du dein erstes persönliches Repository für die Kursübungen anlegst.

## Warum brauchst du ein eigenes Repository?

Ein Repository ist dein persönlicher Arbeitsbereich auf GitHub. Dort speicherst du:
- Deine Lösungen zu Kursübungen
- Deine Code-Dateien und Notizen
- Den kompletten Änderungsverlauf (Commits)

Das Kurs-Repository bleibt zentral und unveränderbar. Dein eigenes Repository ist dein Platz zum Experimentieren und Lernen.

---

## Schritt für Schritt: Repository anlegen

### Schritt 1: GitHub öffnen und einloggen

1. Öffne [github.com](https://github.com) in deinem Browser.
2. Melde dich mit deinem GitHub-Account an (oben rechts: „Sign in").
3. Nach dem Login siehst du dein **Dashboard** mit deinen Repositories.

### Schritt 2: Neues Repository erstellen

1. Oben rechts klickst du auf dein **Profil-Icon** (oder siehst ein **„+"**-Symbol).
2. Klick auf **„New repository"** (oder **„Neues Repository"** auf Deutsch).

**Oder direkt:** Gehe zu [github.com/new](https://github.com/new).

### Schritt 3: Repository-Details ausfüllen

Jetzt siehst du ein Formular. Fülle es so aus:

| Feld | Eingabe | Erklärung |
|------|---------|-----------|
| **Repository name** | `vibe-coding-uebungen` | Gib deinem Repo einen Namen. Du kannst ihn jederzeit ändern. Tipp: Wähle einen Namen, der deinen Kurs wiedergibt. |
| **Description** (optional) | `Meine Übungslösungen für den Vibe Coding Kurs` | Kurze Beschreibung - nicht zwingend, aber hilfreich. |
| **Public / Private** | **Private** | Wähle „Private", damit nur du und eingeladene Personen (z. B. die Trainerin) das Repo sehen. |
| **Initialize with README** | ☑ Häkchen setzen | Das erstellt automatisch eine README.md-Datei. Das ist wichtig! |

### Schritt 4: Repository erstellen

Klick auf den grünen Button **„Create repository"** (oder **„Repository erstellen"**).

---

## Was passiert jetzt?

✅ Dein Repository ist erstellt!

Du siehst jetzt:
- Den Namen deines Repos oben
- Ein leeres oder minimal gefülltes Repository
- Eine **README.md**-Datei (die Datei mit der Dokumentation)
- Den grünen **„Code"-Button** (zum Clonen später)

---

## Nächste Schritte

1. **README bearbeiten:** Öffne die `README.md` und schreib eine kurze Beschreibung über dich und den Kurs.
   - Klick auf die README.md
   - Klick auf das **Stift-Icon** oben rechts
   - Füge deinen Text ein und speichere mit **„Commit changes"**

2. **Repository clonen:** Später lädst du dir dein Repository auf deinen Computer herunter (`git clone ...`).

3. **Lokal arbeiten:** Dann bearbeitest du Dateien auf deinem Computer, commitest sie und pushst sie zu GitHub.

---

## Häufige Fragen

**F: Kann ich den Namen meines Repositories noch ändern?**  
A: Ja! Gehe zu Einstellungen (⚙️) → Settings → Repository name. Wir empfehlen aber, den Namen erst nach dem Anlegen zu ändern.

**F: Was bedeutet „Private"?**  
A: Nur du und die Personen, die du einlädst, können das Repository sehen. Das ist für deine Kursarbeit die richtige Einstellung.

**F: Kann ich ein altes Repository löschen?**  
A: Ja, aber nur, wenn du admin bist. Gehe zu Settings → Danger Zone → Delete this repository. Sei vorsichtig!

**F: Ich sehe den „New Repository"-Button nicht. Wo ist er?**  
A: Versuche es unter [github.com/new](https://github.com/new) direkt.
