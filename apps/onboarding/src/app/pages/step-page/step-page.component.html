Linux: kein offizieller Kurssupport

Wir können für Linux-Setups derzeit keine Fehlerbehandlung leisten. Du kannst Git auf Linux problemlos nutzen – Installation und Problemlösung liegen aber in deiner eigenen Verantwortung.

Je nach Distribution:

  • Debian / Ubuntu: sudo apt-get install git
  • Fedora: sudo dnf install git
  • Arch Linux: sudo pacman -S git
  • openSUSE: sudo zypper install git

Alle weiteren Distributionen: git-scm.com/downloads/linux
info
Nach der Installation siehst du auf git-scm.com: „Now What?"

Die Seite schlägt drei Dinge vor: das Pro Git Buch lesen, eine GUI herunterladen oder mitzumachen. Das kannst du alles ignorieren.

Eine GUI (Graphical User Interface) ist ein Programm mit Klick-Oberfläche, mit dem man Git bedienen kann – ohne Tipp-Befehle. Im Kurs lernst du Git über das Terminal in VS Code, das reicht völlig aus und ist genau das, was in echten Projekten genutzt wird.

Git im Terminal prüfen

Starte VS Code, öffne ein Terminal (Terminal → Neues Terminal) und tippe:

git --version

Erwartetes Ergebnis: git version 2.x.x

Bevor du das Kurs-Repository klonen kannst, muss deine Dozentin deinen GitHub-Account zum Repository einladen.

So weißt du, dass die Einladung angekommen ist:

  • Du erhältst eine E-Mail von GitHub mit dem Betreff „You've been invited to collaborate on a repository".

Noch keine E-Mail erhalten? Sprich deine Dozentin direkt an.
