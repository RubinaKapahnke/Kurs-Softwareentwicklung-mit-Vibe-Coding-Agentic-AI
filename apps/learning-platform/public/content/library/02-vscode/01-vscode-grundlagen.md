# VS Code: Grundlagen und Einstieg

## Was ist Visual Studio Code?
Visual Studio Code (kurz: VS Code) ist ein kostenloser, plattformübergreifender Code-Editor von Microsoft. Er ist besonders beliebt bei Entwickler:innen, weil er leichtgewichtig, schnell und sehr anpassbar ist.

## Wofür wird VS Code genutzt?
VS Code wird für das Schreiben, Testen und Debuggen von Code in vielen Programmiersprachen verwendet. Dank einer riesigen Auswahl an Erweiterungen kann der Editor individuell auf verschiedene Workflows und Technologien angepasst werden.

## Die wichtigsten Features im Überblick
- **Syntax-Highlighting:** Übersichtliche Darstellung von Code in vielen Sprachen
- **IntelliSense:** Smarte Code-Vervollständigung und Hinweise
- **Integrierte Terminal-Konsole:** Befehle direkt im Editor ausführen
- **Quellcodeverwaltung:** Git-Integration für Versionierung und Zusammenarbeit
- **Erweiterungen:** Riesige Auswahl an Plugins für zusätzliche Funktionen
- **Debugging:** Fehler im Code finden und beheben

## Warum ist VS Code ideal für Vibe Coding?
- **Schneller Einstieg:** Auch Anfänger:innen finden sich schnell zurecht
- **KI-Integration:** Tools wie GitHub Copilot lassen sich direkt einbinden
- **Kollaboration:** Gemeinsames Arbeiten an Projekten wird durch Live Share und Git einfach
- **Markdown-Unterstützung:** Dokumentation und Code können im gleichen Editor gepflegt werden
- **Flexibilität:** Für nahezu jede Sprache und jedes Framework geeignet

## Preview Toggle
- Um die Preview-Ansicht einer Datei zu fixieren, verwende die Funktion "Toggle Preview locking" im Overflow-Menu.

---

**Tipp:**
Mit der Tastenkombination `Strg + Shift + P` (Windows) oder `Cmd + Shift + P` (Mac) öffnest du die Befehlspalette - das zentrale Steuerzentrum von VS Code.
