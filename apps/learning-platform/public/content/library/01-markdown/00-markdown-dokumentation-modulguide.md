# Artikel: Markdown

Dieser Artikel erklärt die Grundlagen von Markdown und zeigt dir, wie du Inhalte sauber strukturierst und formatierst.

## Inhaltsverzeichnis

1. [Markdown: Grundlagen und Einsatz](./01-markdown-grundlagen.md)
2. [Formatierung in Markdown-Dateien](./02-formatierung_md-files.md)

## Wissensziele

Nutze die Wissensziele von oben nach unten: erst den Überblick, dann die Grundlagen, dann die Vertiefung.

### Überblick

- [ ] Ich weiß, was Markdown ist und wofür es im Projekt genutzt wird.
- [ ] Ich kann Überschriften (#, ##, ###) schreiben.
- [ ] Ich kann Listen (Aufzählung, nummeriert) erstellen.
- [ ] Ich kann Links schreiben: `[Text](URL)`
- [ ] Ich kann Text-Hervorhebung nutzen: `**fett**`, `*kursiv*`, `` `Code` ``

### Grundlagen

- [ ] Ich kann bestehende Markdown-Dateien lesen und erweitern.
- [ ] Ich strukturiere Inhalte so, dass sie für Menschen und KI lesbar sind.
- [ ] Ich setze Formatierung bewusst ein, statt Text nur hintereinanderzureihen.
- [ ] Ich erkenne typische Markdown-Muster in README-, Artikel- und Übungsdateien.
- [ ] Ich kann Tabellen erstellen.
- [ ] Ich kann Code-Blöcke mit Sprach-Angabe formatieren (```python, ```json etc).

### Vertiefung

- [ ] Ich nutze Markdown als Arbeitsgrundlage für Anforderungen und Notizen.
- [ ] Ich entwickle ein Gefühl dafür, wann eine Datei erklärend und wann nachschlagbar sein sollte.
- [ ] Ich kann erweiterte Markdown-Features wie Fußnoten oder HTML-Kommentare nutzen.
- [ ] Ich schreibe Markdown, das sowohl in GitHub als auch in anderen Tools gut aussieht.
