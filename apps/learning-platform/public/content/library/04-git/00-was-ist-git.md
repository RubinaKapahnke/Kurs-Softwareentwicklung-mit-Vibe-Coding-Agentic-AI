## Wissensziele

Nutze die Wissensziele von oben nach unten: erst den Überblick, dann die Grundlagen, dann die Vertiefung.

### Überblick

- [ ] Ich kann erklären, was Git von GitHub unterscheidet.
- [ ] Ich verstehe Arbeitsordner, Staging Area und Repository.
- [ ] Ich kann mit `git status` meinen aktuellen Stand lesen.

### Grundlagen

- [ ] Ich kann Änderungen mit `git add` und `git commit -m "..."` sauber speichern.
- [ ] Ich kann ein bestehendes Repository mit `git clone` herunterladen.
- [ ] Ich kann einen eigenen Branch erstellen und darin arbeiten.
- [ ] Ich kann meine Änderungen mit `git push` auf GitHub hochladen.
- [ ] Ich kann mit `git pull origin main` vor einer Aufgabe meinen Stand aktualisieren.
- [ ] Ich kann Branches wechseln, ohne meinen Arbeitsstand zu verlieren.
- [ ] Ich kann `git log --oneline` nutzen, um die letzten Commits schneller zu verstehen.
- [ ] Ich weiß, wofür eine `.gitignore` da ist.
- [ ] Ich kann nach getaner Arbeit einen lokalen Branch wieder löschen.
- [ ] Ich weiß, wie ich einen abgeschlossenen Branch vollständig aufräume (lokal + remote + main sync).
- [ ] Ich verstehe, was bei einem Merge-Konflikt grundsätzlich passiert.

### Vertiefung

- [ ] Ich kenne den Unterschied zwischen `git revert` und riskanteren Eingriffen in die Historie.
- [ ] Ich kann unfertige Änderungen kurz mit `git stash` parken.
- [ ] Ich kann Git-Befehle nicht nur ausführen, sondern passend zur Situation auswaehlen.
- [ ] Ich kann typische Fehlersituationen erst mit `git status` analysieren und dann ruhig loesen.
