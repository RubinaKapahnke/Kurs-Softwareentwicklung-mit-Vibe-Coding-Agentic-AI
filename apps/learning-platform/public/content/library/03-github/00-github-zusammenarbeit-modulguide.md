# Artikel: GitHub

Dieser Artikel erklärt die Rolle von GitHub im gemeinsamen Arbeiten an Projekten. Er verbindet die Git-Grundlagen mit Zusammenarbeit, Pull Requests und Projektorganisation auf der Plattform.

## Inhaltsverzeichnis

1. [GitHub: Grundlagen und Einstieg](./01-github-grundlagen.md)

## Wissensziele

Nutze die Wissensziele von oben nach unten: erst den Überblick, dann die Grundlagen, dann die Vertiefung.

### Überblick

- [ ] Ich weiß, was GitHub ist und wie es sich von Git unterscheidet.
- [ ] Ich verstehe die Begriffe Repository, Branch, Pull Request und Issue.
- [ ] Ich kann ein Repository auf GitHub erkunden und den Code durchstöbern.
- [ ] Ich kann den typischen Lebenszyklus einer Änderung auf GitHub erklären.

### Grundlagen

- [ ] Ich kann einen Pull Request sinnvoll vorbereiten und mit einer guten Beschreibung eröffnen.
- [ ] Ich verstehe, wie GitHub die Zusammenarbeit zwischen mehreren Personen unterstützt.
- [ ] Ich kann Code-Kommentare und Feedback auf andere Pull Requests verstehen.
- [ ] Ich weiß, wofür Issues und Diskussionen auf GitHub gut sind.

### Vertiefung

- [ ] Ich kann Pull Requests nicht nur öffnen, sondern auch Reviews durchführen.
- [ ] Ich erkenne, wie Dokumentation, Aufgaben und Code in GitHub zusammenlaufen.
- [ ] Ich nutze GitHub auch für Planung und Diskussion, nicht nur für Code.
- [ ] Ich kann GitHub Actions oder andere erweiterte Features explorieren.
