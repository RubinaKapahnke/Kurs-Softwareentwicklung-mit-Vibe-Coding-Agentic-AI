# tools/

Dieser Ordner enthält Skripte für den **Kursbetrieb** – sie werden von Dozenten und KI-Agenten genutzt, um Übungsdateien automatisch auf Vollständigkeit zu prüfen.

**Als Lernende/r musst du hier nichts tun.** Dein Arbeitsbereich ist:

- [`apps/learners/<dein-name>/`](../apps/learners/) → deine persönlichen Dateien
- [`docs/uebungen/`](../docs/uebungen/) → zentrale Übungsaufgaben
- [`modules/`](../modules/) → Lernmaterial
