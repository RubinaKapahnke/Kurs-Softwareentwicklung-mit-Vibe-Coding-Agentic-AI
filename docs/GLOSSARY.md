| Begriff           | Erklärung |
|-------------------|-----------|
| **Markdown**      | Eine leichtgewichtige Auszeichnungssprache zur einfachen Formatierung von Texten, oft genutzt für Dokumentation und Readmes. |
| **VS Code**       | Ein kostenloser, plattformübergreifender Code-Editor von Microsoft mit vielen Erweiterungen und starker KI-Integration. |
| **GitHub**        | Eine Plattform zur Versionsverwaltung und Zusammenarbeit an Softwareprojekten, basierend auf Git. |
| **Git**           | Ein verteiltes Versionskontrollsystem zur Nachverfolgung von Änderungen und Zusammenarbeit an Code. |
| **Terminal**      | Ein Text-basiertes Werkzeug zur direkten Eingabe von Befehlen und Steuerung des Computers. |
| **Prompting**     | Das gezielte Formulieren von Eingaben (Prompts), um KI-Modelle zu steuern und gewünschte Ergebnisse zu erhalten. |
| **Branch**        | Ein Entwicklungszweig in Git/GitHub, um unabhängig neue Features oder Bugfixes zu entwickeln. |
| **Commit**        | Eine gespeicherte Änderung im Versionsverlauf eines Git-Repositories. |
| **Repository**    | Ein Speicherort für ein Softwareprojekt inklusive aller Dateien und der Versionshistorie. |
| **Pull Request**  | Ein Vorschlag für Änderungen an einem GitHub-Repository, der diskutiert und zusammengeführt werden kann. |
| **Issue**         | Ein Eintrag auf GitHub zur Verwaltung von Aufgaben, Fehlern oder Ideen. |
| **KI-Agent/KI-Tool** | Ein Programm, das Künstliche Intelligenz nutzt, um Aufgaben zu unterstützen oder zu automatisieren (z. B. Copilot, ChatGPT). |
